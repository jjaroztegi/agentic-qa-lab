# CP-008 An order without coils cannot be completed or reported to the ERP

## Application Overview

The ERP (Odoo, standing in for SAP) creates a manufacturing order when a made-to-order sales order is
confirmed. The in-house MES picks up confirmed manufacturing orders (sync every ~10 s) and lists them
as "Pending". On the MES order screen the shift supervisor registers coils and then completes the
order, which reports the production back to the ERP. An order with no coils must not be completable.

#### 1.1 CP-008 An order without coils cannot be completed or reported to the ERP

**File:** `tests/e2e/cp-008-order-without-coils-cannot-be-completed.spec.ts`

**Precondition (created by the test, not part of the case steps):**
- The case has no data (`data: {}`). The test repeats the most recent sales order in the ERP: same
  customer, product and quantity (today: "Northline Fabrication Ltd.", "Hot-rolled coil S275JR",
  10 t), created and confirmed through the ERP API as the sales rep.
- The ERP creates the manufacturing order (`WH/MO/xxxxx`, state confirmed) and the MES receives it
  as a "Pending" order with no coils. No coils are registered (so no `C-<RUN>-n` numbers are needed).

**Steps:**
1. Open the order in the MES
   - MES home → "Manufacturing orders" list → row of the new sales order → click the ERP order link
   - expect: the heading reads "Order WH/MO/xxxxx" and the Coils table shows "No coils registered."
   - expect: the "Complete order" button is disabled

**Data checks:**
- MES `GET /api/orders/{ERP order}`: status is still not completed (not `completed` / `reported`), no coils
- ERP `mrp.production` of the order: state is still `confirmed`
